# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public GitHub issue
for a security problem.

Email **kshtzkr@gmail.com** with a description of the issue, the affected version, and
steps to reproduce it. You can expect an acknowledgement within about a week. Once the
issue is confirmed, a fix will be released and the report credited if you would like.

Please do not include secrets, access tokens, or personal data in your report.

## Supported versions

The latest `0.1.x` release receives security fixes. Older versions are not maintained;
upgrade to the latest release to stay covered.

| Version | Supported |
|---|---|
| 0.1.x (latest) | yes |
| older | no |
